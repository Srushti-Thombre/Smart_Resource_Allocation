**Solving UN Sustainable Development Goals: 1 (No Poverty), 2 (Zero Hunger), & 17 (Partnerships for the Goals)**


**🚀 Overview**
**ImpactBridge** is a high-performance, AI-integrated ecosystem designed to streamline how NGOs, volunteers, and corporate partners collaborate. In a world where aid coordination is often fragmented and opaque, ImpactBridge provides a **Single Source of Truth** for resource allocation, ensuring that the right help reaches the right people at the right time.

**✨ Key Features**

**📍 Live Impact Heatmap**
Our standout feature—a real-time geographic visualization of resource demand. It uses data-driven intensity mapping to identify "Aid Deserts" and "High-Need Zones," allowing stakeholders to prioritize efforts with surgical precision.

**🎭 Triple-Portal Architecture**
Tailored, role-specific experiences for the three pillars of social impact:
*   **NGOs:** Command centers to broadcast needs, manage volunteers, and track funding.
*   **Volunteers:** Interactive discovery feed and "My Tasks" management for skilled contributions.
*   **Corporate Partners:** Transparent "Impact Feeds" to monitor CSR initiatives and witness real-world results.

**🤝 Smart Matching & Transparency**
*   **AI-Ready Engine:** Designed to pair volunteer skills (Medical, Tech, Logistics) with urgent community needs.
*   **Live Progress Tracking:** Real-time visual progress bars for every initiative, ensuring 100% accountability for donors.
*   **Verified Ecosystem:** Automated NGO verification and secure role-based access.

**🛠️ Tech Stack**
*   **Frontend:** React 18, Vite, Tailwind CSS
*   **Icons:** React Icons (HiOutline)
*   **Styling:** Premium Glassmorphism & Dark Mode Aesthetic
*   **Animations:** Framer Motion-style CSS transitions & keyframe effects
*   **Data Flow:** Context API for real-time state management

**🌍 UN SDG Alignment**
*   **SDG 1 & 2:** Rapid and efficient allocation of food, water, and medical resources.
*   **SDG 17:** Building a technology-driven bridge between the private sector and humanitarian organizations.

**🏁 Getting Started**

**Prerequisites**
*   Node.js (v18 or higher)
*   npm or yarn

**Installation**
1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Srushti-Thombre/Smart_Resource_Allocation.git
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Run the development server:**
    ```bash
    npm run dev
    ```
