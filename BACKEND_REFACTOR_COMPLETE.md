## Complete API Implementation

### All 8 Endpoints Working

```javascript
// REQUEST ENDPOINTS (7)
POST   /api/requests                    // Create request
GET    /api/requests                    // Get all requests
GET    /api/requests?type=volunteer     // Filter volunteer
GET    /api/requests?type=funding       // Filter funding
GET    /api/requests/:id                // Get single
POST   /api/requests/:id/accept         // Accept request
POST   /api/requests/:id/close          // Close request

// DONATION ENDPOINTS (3+)
POST   /api/donate                      // Create donation
GET    /api/donate                      // Get all donations
GET    /api/donate?ngoName=...          // Filter by NGO
GET    /api/donate?companyName=...      // Filter by company
GET    /api/donate/stats/:ngoName       // Get stats

// HEALTH CHECK
GET    /api/health                      // Server status (returns counts)
```

## Setup Instructions

### 1. Install Dependencies (1 min)

```bash
cd backend
npm install
# Only installs: express, cors, dotenv
# No MongoDB required! ✅
```

### 2. Start Server (instant)

```bash
npm run dev
# Output:
# 🚀 Server running on http://localhost:5000
# 📊 Using in-memory storage (demo mode)
# ⚠️  Data will be lost on server restart
```

### 3. Test Endpoints

```bash
# Health check
curl http://localhost:5000/api/health

# Create request
curl -X POST http://localhost:5000/api/requests \
  -H "Content-Type: application/json" \
  -d '{"title":"Test","description":"Test","type":"volunteer","ngoName":"Test NGO"}'

# Get all requests
curl http://localhost:5000/api/requests
```
